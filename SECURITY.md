# Security and sensitive information

Do not post secrets, private workspaces, or exploitable details with sensitive payloads in public issues. Contact the maintainer through the public contact route in README and ask for a private reporting channel before sharing sensitive details.

For an accidentally exposed credential, revoke it with the provider first. For a non-sensitive packaging or validation bug, a minimal fictional reproduction in an issue is welcome.

The assistant instructions and release checks reduce common mistakes; they are not an access-control system. This project has no hosted service and no guarantee of response time. See docs/PRIVACY.md for publication boundaries.
