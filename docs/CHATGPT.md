# Use a chat without local file access

Open CHATGPT-START.txt and paste its contents into your chosen chat. This self-contained prompt includes the interview protocol, safety boundaries, and core templates. No connector is required.

For the delivery example, attach examples/supply-check/input.csv and paste its README instructions. Do your own attempt before opening expected-result.md.

Ask for named text blocks or downloadable files. Save the documents under your local workspace/projects/first-task folder, and save onboarding.md and progress.md under workspace. In a new chat, attach these saved files. Chat history alone is not a reliable project handoff.

Do not claim that an assistant has local access unless its tools actually provide it. ChatGPT Work or connected tools may offer additional file capabilities; use the capabilities actually present in your session.
