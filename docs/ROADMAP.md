# Roadmap

## Included in v1.0.0

English beginner path; adaptive interview and resume state; task/workflow/check templates; optional learning milestones; generic orchestration architecture; fictional delivery and meeting examples; team handoff guidance; reproducible allowlisted ZIP build; repository validation and automated tests.

## Next, after learner feedback

- Observe first-time users completing and resuming a task; record where they need help.
- Improve interview branches based on observed friction.
- Add contributor-reviewed fictional examples from other roles.
- Evaluate accessibility and language clarity with learners.

## Possible later work

Tested tool-specific onboarding, translated editions, optional integration demos, and facilitated training materials. These are ideas, not installed features or delivery promises. There is no live connector, automatic scheduler, or hosted memory service in v1.0.0.
