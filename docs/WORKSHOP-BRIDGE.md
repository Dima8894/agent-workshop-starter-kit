# From your paper worksheet to a checked artifact

The Agent Workshop practice starts with designing one task on paper. This starter kit is the next step: try a small part of that design with an assistant. A paper diagram is not yet a deployed automation.

Bring a worksheet photo or a written description. Keep private company details out of the image. The assistant maps the design to task.md and workflow.md, confirms consequential gaps, and selects one feasible artifact.

| Your paper design | In the workspace |
| --- | --- |
| Goal, trigger, recipient | task.md |
| Context and examples | inputs/ and source references |
| Observe, reason, skill, act | workflow.md |
| Tools and access | workflow.md; later integration.md |
| Verification and stop rules | checks.md |
| Result | results/ |
| What to remember | current state and confirmed decisions |

Example: “monitor deliveries and notify suppliers” becomes a first local exception report from a fictional CSV. Sending notifications is a later, separately authorized integration.

After the first result, follow the learning path: repeat on new data, write a reusable procedure, organize additional projects, and hand work to a colleague. The kit is usable independently of a workshop or a commercial course.
